# 🎨 Portfolio Website

A personal portfolio website built with **React** and **Vite**, showcasing my skills, projects, and contact information.

## 📁 Project Structure

```
portfolio/
├── src/
│   ├── pages/
│   │   ├── Home.jsx        # Landing/Home page
│   │   ├── About.jsx       # About Me page
│   │   └── Contact.jsx     # Contact page
│   ├── components/
│   │   ├── Navbar.jsx      # Navigation bar
│   │   ├── Footer.jsx      # Footer
│   │   ├── Loader.jsx      # Loading spinner
│   │   ├── Modal.jsx       # Modal component
│   │   └── ShowingModal.jsx
│   ├── styles/
│   │   └── Navfoo.css      # Navbar & Footer styles
│   ├── apis/
│   │   ├── hire.js         # Hire API
│   │   └── skills.js       # Skills data
│   ├── App.jsx             # Main App with routing
│   ├── App.css             # Global styles
│   └── index.jsx           # Entry point
├── public/
│   └── favicon.svg
├── index.html
├── vite.config.js
└── package.json
```

## 🚀 Features

- 🏠 **Home Page** — Introduction and hero section
- 👤 **About Page** — Skills and background
- 📬 **Contact Page** — Get in touch form
- ⚡ **Fast loading** with lazy loading and Suspense
- 📱 **Responsive design** using MDB UI Kit
- 🎨 **Custom fonts** with Google Fonts (Josefin Sans)

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React | UI Library |
| Vite | Build Tool |
| React Router DOM | Page Routing |
| MDB UI Kit | CSS Framework |
| Font Awesome | Icons |
| Google Fonts | Typography |

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Priyanshu-singh11/Class-9th-projects.git
   cd Class-9th-projects
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`
