# 🎓 Class 9th Projects

A collection of web development projects built during Class 9th using **React**, **Vite**, and modern JavaScript. Each project is in its own folder with its own README and setup instructions.

---

## 📂 Projects

### 1. ✅ [Todo List App](./todo-list/)

> A fully functional Todo List with add, update, complete, delete, and clear-all features. Data is saved to localStorage so tasks survive page refresh. Built with React + Vite + React Toastify.

**Key Features:**
- Add / Update / Delete tasks
- Mark tasks as complete (strikethrough)
- Toast notifications for every action
- LocalStorage persistence

**Tech:** React, Vite, React Toastify, CSS

👉 [Go to project →](./todo-list/)

---

### 2. 🧑‍💻 [Developer Portfolio](.)

> A personal portfolio website with Home, About, and Contact pages. Showcases skills and platforms where you can hire the developer.

**Key Features:**
- Multi-page layout (Home / About / Contact)
- Skills showcase with modals
- Hire me section
- Lazy loading images

**Tech:** React, Vite, React Router, Bootstrap, CSS

## 🛠️ How to Run Any Project

```bash
# Clone the repo
git clone https://github.com/Priyanshu-singh11/Class-9th-projects.git

# Go into a project folder
cd Class-9th-projects/todo-list

# Install dependencies
npm install

# Start the dev server
npm run dev
```
