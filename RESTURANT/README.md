# 🍽️ Restaurant Web App

A modern restaurant web application built with **React** and **Vite**. Browse food categories, search dishes, explore cuisines, and view detailed recipes — all in a clean, responsive UI.

---

## 📸 Features

- 🔍 **Search** — Search for any dish or recipe by name
- 🗂️ **Categories** — Browse food by category (Vegan, Pasta, Seafood, etc.)
- 🌍 **Cuisines** — Explore dishes by world cuisine
- 🥗 **Popular & Vege Picks** — Curated popular and vegetarian dishes
- 📄 **Recipe Details** — Full recipe with ingredients and instructions
- ⚡ **Fast & Responsive** — Built with Vite for lightning-fast dev experience

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| React | UI framework |
| Vite | Build tool & dev server |
| React Router | Client-side routing |
| React Icons | Icon library |
| Font Awesome | Additional icons |
| CSS (custom) | Styling |

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/Priyanshu-singh11/Class-9th-projects.git

# 2. Go into the project folder
cd Class-9th-projects/RESTURANT

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.
